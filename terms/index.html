1. ขอบเขต

ข้อกำหนดนี้ใช้กับ BTK Media System ("แอป") ซึ่งเป็นระบบภายในของห้างหุ้นส่วนจำกัด บีทีเค มีเดีย โปรดักชั่น ("ห้าง") ผู้ใช้แอปได้คือพนักงานหรือผู้ที่ห้างมอบสิทธิ์เท่านั้น แอปไม่ได้ให้บริการแก่บุคคลทั่วไป

2. การเชื่อมต่อ TikTok

  • แอปใช้ TikTok Login Kit เชื่อมต่อได้เฉพาะบัญชี TikTok ที่ห้างเป็นเจ้าของ
  • แอปใช้ Content Posting API โพสต์เฉพาะคลิปที่ห้างผลิตและมีพนักงานกดอนุมัติแล้ว ระบบไม่โพสต์คลิปที่ยังไม่ได้รับอนุมัติ
  • คลิปที่สร้างด้วย AI จะเปิดป้าย "AI-generated content" และคลิปที่มีลิงก์ affiliate จะเปิดเผยว่าเป็นเนื้อหาเชิงพาณิชย์ตามกฎของ TikTok
  • การใช้งานต้องเป็นไปตาม ข้อกำหนดการให้บริการของ TikTok และ แนวทางชุมชน

3. หน้าที่ของผู้ใช้

  • ตรวจคลิปก่อนอนุมัติว่าถูกต้อง ไม่ละเมิดลิขสิทธิ์ ไม่กล่าวอ้างเกินจริง และเป็นไปตามกฎหมายและกฎของแพลตฟอร์ม
  • ไม่ใช้แอปปั่นยอด สแปม หรือควบคุมบัญชีจำนวนมาก
  • เก็บรักษาข้อมูลเข้าสู่ระบบเป็นความลับ

4. ข้อมูลส่วนบุคคล

การเก็บและใช้ข้อมูลเป็นไปตาม นโยบายความเป็นส่วนตัว

5. การระงับและยกเลิก

ห้างอาจระงับการโพสต์หรือสิทธิ์ผู้ใช้ได้ทุกเมื่อ เจ้าของบัญชีสามารถยกเลิกสิทธิ์ของแอปได้ในการตั้งค่า TikTok

6. ข้อจำกัดความรับผิด
