ภาษาไทย

1. ผู้ควบคุมข้อมูล

ห้างหุ้นส่วนจำกัด บีทีเค มีเดีย โปรดักชั่น ("ห้าง" หรือ "เรา") เป็นผู้ให้บริการระบบภายใน BTK Media System ("แอป") ติดต่อเรื่องข้อมูลส่วนบุคคลได้ที่ btkmediaproduction@gmail.com

2. แอปทำอะไร

แอปเป็นเครื่องมือภายในของห้าง ใช้ TikTok Login Kit เพื่อให้พนักงานของห้างเชื่อมต่อบัญชี TikTok ของห้างเอง และใช้ Content Posting API เพื่อโพสต์คลิปวิดีโอที่ห้างผลิตและพนักงานอนุมัติแล้วลงบัญชีนั้นเท่านั้น แอปไม่เปิดให้บุคคลภายนอกเชื่อมบัญชี ไม่โพสต์ลงบัญชีของผู้อื่น และไม่อ่านข้อความส่วนตัว รายชื่อผู้ติดตาม หรือข้อมูลของผู้ใช้ TikTok คนอื่น

3. ข้อมูลที่เราเก็บ

ข้อมูลได้มาจากใช้เพื่อ
ตัวระบุบัญชี TikTok ของห้าง (open_id), ชื่อที่แสดง และรูปโปรไฟล์TikTok Login Kit (scope user.info.basic)แสดงว่าเชื่อมกับบัญชีใด และตรวจว่าเป็นบัญชีของห้าง
Access token และ refresh tokenTikTok OAuthเรียก Content Posting API แทนบัญชีของห้าง
รหัสการโพสต์ (publish_id), สถานะการโพสต์ และลิงก์คลิปContent Posting API (scope video.upload / video.publish)ตรวจว่าโพสต์สำเร็จ และไม่โพสต์ซ้ำ
ไฟล์คลิป แคปชัน และบันทึกการอนุมัติห้างผลิตเองผลิตและโพสต์คลิป เก็บหลักฐานว่าใครอนุมัติเมื่อใด
บัญชีผู้ใช้ของพนักงาน (ชื่อ อีเมลงาน บทบาท)ห้างสร้างให้ควบคุมสิทธิ์เข้าใช้งานและบันทึกการทำงาน

เราไม่เก็บรหัสผ่าน TikTok ไม่เก็บข้อมูลของผู้ชมหรือผู้ติดตาม และไม่ใช้ข้อมูลจาก TikTok เพื่อโฆษณา ขาย หรือส่งต่อให้บุคคลอื่น

4. การเก็บรักษาและความปลอดภัย

  • Token ถูกเข้ารหัส (Fernet/AES) ก่อนบันทึกลงฐานข้อมูล คีย์เข้ารหัสเก็บแยกในค่าตั้งของเซิร์ฟเวอร์ ไม่อยู่ในซอร์สโค้ด
  • ฐานข้อมูลและไฟล์คลิปเก็บบนผู้ให้บริการคลาวด์ที่ห้างใช้ (ฐานข้อมูล Postgres และที่เก็บไฟล์แบบ S3) เข้าถึงได้เฉพาะพนักงานที่ได้รับสิทธิ์
  • ทุกการเปลี่ยนสถานะคลิปและการโพสต์ถูกบันทึกใน audit log

5. ระยะเวลาเก็บ

  • Token: เก็บเท่าที่บัญชียังเชื่อมต่ออยู่ ลบทันทีเมื่อยกเลิกการเชื่อมต่อ
  • ข้อมูลโปรไฟล์บัญชีของห้าง: เก็บเท่าที่บัญชียังเชื่อมต่อ
  • บันทึกการโพสต์และการอนุมัติ: เก็บตามระยะเวลาที่กฎหมายบัญชีและภาษีกำหนด เพราะใช้คำนวณรายได้ค่าคอมมิชชัน

6. การลบข้อมูล

  • ยกเลิกสิทธิ์ของแอปได้ทุกเมื่อในแอป TikTok: Settings and privacy → Security → Manage app permissions แล้วลบ BTK Media System เมื่อสิทธิ์ถูกยกเลิก token เดิมจะใช้ไม่ได้ และแอปจะลบ token ที่เก็บไว้
  • ขอให้ลบข้อมูลที่เกี่ยวกับบัญชี TikTok ได้ทางอีเมล btkmediaproduction@gmail.com เราจะลบภายใน 30 วัน ยกเว้นข้อมูลที่กฎหมายบังคับให้เก็บ (ซึ่งจะลบเมื่อพ้นระยะเวลาดังกล่าว)

7. สิทธิ์ของเจ้าของข้อมูล

ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) ท่านมีสิทธิ์ขอเข้าถึง ขอสำเนา แก้ไข ลบ คัดค้าน หรือถอนความยินยอม โดยติดต่อทางอีเมลข้างต้น

English

1. Who we are

BTK Media Production Limited Partnership ("BTK", "we") operates BTK Media System (the "App"), an internal tool. Contact us about personal data at btkmediaproduction@gmail.com.

2. What the App does

The App uses TikTok Login Kit so our staff can connect the company's own TikTok account, and the Content Posting API to publish videos that we produce and that a member of staff has approved to that account only. The App does not let the public connect accounts, never posts to anyone else's account, and does not read private messages, follower lists or other TikTok users' data.

3. Data we collect

DataSourcePurpose
The company account's TikTok identifier (open_id), display name and avatarTikTok Login Kit (user.info.basic scope)Show which account is connected and confirm it is ours
Access token and refresh tokenTikTok OAuthCall the Content Posting API on behalf of the company account
Publish IDs, post status and video linksContent Posting API (video.upload / video.publish scopes)Confirm a post succeeded and prevent duplicate posts
Video files, captions and approval recordsProduced by usProduce and post videos; keep a record of who approved each one and when
Staff user accounts (name, work email, role)Created by usAccess control and activity logging

We do not store TikTok passwords, do not collect data about viewers or followers, and do not use TikTok data for advertising, sell it or share it with third parties.

4. Storage and security

  • Tokens are encrypted (Fernet/AES) before they are stored. The encryption key is kept in server configuration, not in source code.
  • The database and video files are stored with the cloud providers we use (a Postgres database and S3-compatible file storage), accessible only to authorised staff.
  • Every status change and post is recorded in an audit log.

5. Retention

  • Tokens: kept only while the account is connected; deleted as soon as it is disconnected.
  • Company account profile data: kept only while the account is connected.
  • Post and approval records: kept for the period required by Thai accounting and tax law, because they are used to account for commission income.

6. Deleting your data

  • You can revoke the App's access at any time in the TikTok app: Settings and privacy → Security → Manage app permissions, then remove BTK Media System. Revoked tokens stop working and the App deletes the stored tokens.
  • To request deletion of data related to a TikTok account, email btkmediaproduction@gmail.com. We delete it within 30 days, except data we are legally required to keep (deleted when that period ends).

7. Your rights

Under Thailand's Personal Data Protection Act B.E. 2562 (PDPA) you may request access to, a copy of, correction or deletion of your data, object to processing, or withdraw consent by emailing us.

8. Changes

If we change this policy we will update the effective date on this page.
